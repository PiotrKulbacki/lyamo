# S01 — bezpieczna granica przeglądarki

Cel: usunąć niekontrolowane przekierowanie, pętlę nieaktualnej sesji i ujednolicić ochronę żądań z ciasteczkiem. Zależność: S00. Następne: S02.

## Zakres

- Waliduj `redirect` przed nawigacją: wyłącznie dozwolone ścieżki tej aplikacji. Odrzuć schematy wykonywalne, adresy zewnętrzne, `//`, backslash i warianty kodowania; bezpieczny fallback do dashboard.
- Usuń założenie, że obecność `sec_session` oznacza ważną sesję. Nie odsyłaj z /login ani stron odzyskiwania do panelu na podstawie samego ciasteczka; usuwaj nieaktualny stan w dozwolonym miejscu serwera.
- Zaprojektuj wspólną ochronę CSRF dla modyfikujących operacji korzystających z cookies: pochodzenie i typ treści, ewentualny token zgodnie z wybranym wzorcem. Uwzględnij także login CSRF. SameSite jest dodatkową ochroną.
- Nie obejmuj tym wymogiem podpisanych webhooków Stripe ani nie blokuj prawidłowego callbacku Google. Rozróżnij rzeczywiste Bearer auth mobile od żądania z dodanym, niepoprawnym nagłówkiem, które spada do cookies.
- Ujednolić ustawianie/czyszczenie cookies; rozważ prefiks `__Host-` z planem wygaszenia starej nazwy. Zachowaj działanie localhost i poprawne atrybuty produkcyjne.

## Pliki startowe

`apps/web/src/features/auth/components/AuthForm.tsx`, `apps/web/src/middleware.ts`, `apps/web/src/features/auth/services/auth.service.ts`, `apps/web/src/features/auth/lib/request-auth.ts`, `apps/web/src/app/(app)/layout.tsx`, API auth i mutujące API używające cookies. Skille platformowe tylko do rzeczywistego wdrożenia.

## Kryteria odbioru

- E2E: bezpieczny powrót po logowaniu; złośliwy redirect nie wykonuje skryptu i nie opuszcza aplikacji.
- Brak pętli dla sesji wygasłej, nieznanej i usuniętej; dostępne logowanie/reset.
- Żądanie z obcego pochodzenia jest odrzucane, prawidłowe web i mobile działają; nieznany Bearer nie omija ochrony cookies.
- Callback Google i podpisany webhook zachowują swój własny model zabezpieczeń.

Bez zmiany modelu łączenia kont i cyklu tokenów. Raport reports/S01.md opisuje wspólne zabezpieczenie do wykorzystania przez następne etapy.
